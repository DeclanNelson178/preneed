The page did not start

Open this over http, not straight from the file

A browser blocks JavaScript modules on a file:// page. The dashboard builds every input field and every chart in JavaScript, so it cannot build. Nothing is broken. The page needs a web address.

Start a small server in this folder, then open the address it prints:

cd /Users/declannelson/Desktop/code/preneed
python3 -m http.server 8000

Then open http://localhost:8000. On a Mac you can also double-click serve.command in this folder, which does both steps for you. On GitHub Pages the page is already served over http, so this notice never appears there.
